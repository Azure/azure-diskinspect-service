# Windows Update Diagnostic Manifests

Use with `diagnostic-provisioning` for in-place upgrade failures because WGA upgrade rules also depend on Panther setup logs and scan results.

| Manifest | Area | Description | PII Risk |
|----------|------|-------------|----------|
| `diagnostic-windows-update` | Update | Servicing sessions, CBS, DISM, WindowsUpdate, WindowsUpdateClient event log | Medium |
